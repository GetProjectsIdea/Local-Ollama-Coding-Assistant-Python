```python
def is_palindrome(text):
    # Remove spaces and convert to lowercase
    cleaned_text = text.replace(" ", "").lower()
    
    # Check if the cleaned text is equal to its reverse
    return cleaned_text == cleaned_text[::-1]

# Example usage
example_text = "A man a plan a canal Panama"
print(is_palindrome(example_text))  # Output: True
```

   - It then converts the text to lowercase using `text.lower()`. This ensures that the palindrome check is case-insensitive.

2. **Checking for Palindrome**:
   - The function checks if the cleaned text is equal to its reverse. This is done using slicing `cleaned_text[::-1]`, which creates a reversed version of the string.
   - If the cleaned text is the same as its reverse, the function returns `True`, indicating that the text is a palindrome.
