**What this code does**

1. `def average(nums)` defines a function that takes a list of numbers.
2. `sum(nums)` adds them and `len(nums)` counts them.
3. It returns the total divided by the count, i.e. the mean.

**Watch out:** an empty list makes `len(nums)` zero, so Python raises `ZeroDivisionError`.

[3] fix (en)
------------------------------------------------------------
**Why it fails:** `average([])` divides by `len([])`, which is 0, so Python raises `ZeroDivisionError` on line 2.

**Fixed code:**

```python
def average(nums):
    if not nums:
        return 0.0
    return sum(nums) / len(nums)
```

**Tip:** always decide what an empty input should return.

[4] docstring (en)

```python
def average(nums):
    """Return the arithmetic mean of a list of numbers.

    Args:
        nums: A non-empty list of int or float values.

    Returns:
        float: The average value.

    Raises:
        ZeroDivisionError: If ``nums`` is empty.
    """
    return sum(nums) / len(nums)
```
